Chili

Description

This recipe is for an amazing chili that is not for the faint of heart. The chili recipe here is extremely good if you are like me and REALLY like chili. I would not recommend the use of this recipe if you don't like chili.

Ingredients

  • a lot of kidney beans
  • half a bottle of chili powder
  • can o tomato sauce
  • meat if u want it
  • noodles if u r into that
  • toppings like cheese and crackers

Steps

  1. if you want meat then cook now to your liking
  2. add tomato sauce, beans, noodles-if wanted-, and chili powder
  3. bring to boil
  4. simmer till desired consistency
  5. add more chili powder if required
  6. if wanted add your topings
  7. serve
